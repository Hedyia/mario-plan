# aura-instagram

ملفات بوستات انستجرام لحساب @auracliniccrm. الفرع ده مستقل عن كود المشروع، ومعمول عشان انستجرام يقدر يسحب الصور والفيديوهات من لينك عام وقت النشر.

- `queue.json`: جدول النشر. كل عنصر فيه التاريخ ونوع البوست (story / carousel / image / reel) واللينكات والكابشن.
- `tools/render.py`: تصميم البوستات والكاروسيل والستوري من ملف JSON.
- `tools/reel.py`: ريلز موشن جرافيك 1080x1920 من ملف JSON. أشكال المشاهد: hook, quote, chat, timeline, formula, receipt, punch, storycard, endcard، والجديد: kinetic (كلام كبير بيظهر سطر سطر)، pov (موقف بإيموجي)، checklist (مهام بتاخد ✕ أو ✓)، split (قبل وبعد)، phone (موبايل عليه إشعارات)، counter (رقم بيعد). وكل مشهد ممكن يتغير خلفيته بـ bg: paper / solid / grid.
- `tools/music.py`: موسيقى أصلية هادية (من غير حقوق) بتتضاف أوتوماتيك لكل ريل وستوري. ممنوع ننشر فيديو ساكت.
- `tools/edit_real.py`: مونتاج فيديو حقيقي صوّره الفريق: قص 9:16، وهوك في أول 3.5 ثانية، ولوجو، وكارت "تابعنا" في الآخر. لو الفيديو بالعرض (تسجيل شاشة لابتوب) بيتحط جوه إطار جهاز على خلفية البراند والهوك فوقه طول الفيديو (--fit frame).
- `backlog-*`: ريلز جاهزة لسه ملهاش ميعاد، مكتوبة في queue.json تحت backlog.
- كل مجلد بتاريخ = بوست واحد. الصور JPEG لأن انستجرام مش بيقبل غيره.
