# aura-instagram

ملفات بوستات انستجرام لحساب @auracliniccrm. الفرع ده مستقل عن كود المشروع، ومعمول عشان انستجرام يقدر يسحب الصور والفيديوهات من لينك عام وقت النشر.

- `queue.json`: جدول النشر. كل عنصر فيه التاريخ ونوع البوست (story / carousel / image / reel) واللينكات والكابشن.
- `tools/render.py`: تصميم البوستات والكاروسيل والستوري من ملف JSON.
- `tools/reel.py`: ريلز موشن جرافيك 1080x1920 من ملف JSON.
- `tools/edit_real.py`: مونتاج فيديو حقيقي صوّره الفريق: قص 9:16، وهوك في أول 3.5 ثانية، ولوجو، وكارت "تابعنا" في الآخر.
- كل مجلد بتاريخ = بوست واحد. الصور JPEG لأن انستجرام مش بيقبل غيره.
